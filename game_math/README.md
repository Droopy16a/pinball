# Pinball mathematics

Python 3.12+; install `pip install -e './game_math[dev]'`. The original probability, payout, and simulation utilities remain available.

The pinball publisher consumes `physics-traces.json`, generated by the actual original Expert/Matter.js implementation through `node scripts/generate-physics.mjs` while the local frontend is running. It adds monetary annotations without changing any physical sample. The Math SDK path defaults to `.reference/math-sdk`; specify `--sdk` for another checkout.

```powershell
.venv/Scripts/python.exe game_math/src/game_math/pinball.py
.venv/Scripts/python.exe -m pytest game_math
```

Artifacts: `library/publish_files/index.json`, seven compressed event books, seven lookup CSVs, and `library/pinball-report.json`. The frontend's `public/demo-books.json` uses the same events and weights.

Each scoring operation has a fixed price: `max(10, floor((points + 125) / 250) * 10)` in hundredths of the stake. +1,000 points always pays 0.4× and +10,000 always pays 4×. Each of the two native middle bumpers divides the collected bank by two; Fraction/BigInt preserve exact values, even after repeated hits. At the final natural drain, the payout rounds upward to the next 0.1× stake, matching the RGS publication resolution without discarding small awards.

`balance_weights` adjusts only integer sampling weights so the exact payout expectation is 967/1000 in each mode. No per-round scaling, tier assignment or payout-forcing path edits occur. The current library contains 99 verified trajectories (14 per mode, 15 for POWER_90 to include a native bonus cutscene). Both the demo and upload files use the same events and weights.

The current 99-shot library is for development. Live math acceptance and production diversity have not been established. See `docs/stake-engine.md` for the event contract and lifecycle.
